Generates a 1024x1024 PNG entry image summarizing world news for 17 November 2026, built with Python Pillow (PIL). The image features four news categories — Geopolitics, Science, Sport, Markets — laid out in styled panels on a dark canvas with an accent bar, centered title, and a footer caption.

## Run it

```sh
python3 main.py
```

Output is written to `/output/entry.png` (override with `MAKEFUN_OUT_DIR`).

- `main.py` — PIL entry generator (authored in this session)
- `entry.png` — generated 1024x1024 entry image
